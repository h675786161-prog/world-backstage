# 世界背面

> **镜头之外，世界仍在继续。**

**World Backstage / 世界背面** 是一个为 SillyTavern 设计的世界状态与长期连续性扩展。  
正文负责呈现眼前的故事，世界背面负责维护镜头之外仍然成立的时间、人物、事件、认知、记忆与因果。

**当前 manifest 版本：2.5.8**  
`main` 已合并 2026-09-25 的 **长篇记忆回读** 与 **自动隐藏已归档楼层** 更新。自动隐藏默认关闭。

## 它在做什么

世界背面维护的是**世界状态本身**，不是给模型追加几句“请记住前文”的提示词。

- **主世界时间**：统一管理世界当前时间与事件进度。
- **人物状态**：记录位置、行动、意图、认知边界与幕后状态。
- **暗流与回声**：让事件拥有起因、推进、结果和后续影响。
- **长期记忆**：把长聊天整理成逐楼摘要、持续经历、长期事实与伏笔。
- **剧情回读**：需要回忆早期约定、暗号、交接、动作顺序时，优先找回对应旧楼层记忆。
- **自动隐藏旧楼层**：只有在逐楼记忆覆盖后，才把更早正文从模型上下文隐藏；聊天记录仍保留。
- **世界舆情与传播**：新闻、论坛、消息和角色获知路径遵守真实传播链。
- **通讯与玲七管家**：复用世界里真实存在的人物与状态，不建立第二套互相打架的数据。

一句话：

> **正文是镜头，世界背面是镜头之外仍然成立的世界。**

## 安装

### 从 GitHub 安装

1. 打开 SillyTavern 的扩展管理页面。
2. 选择“安装扩展”。
3. 粘贴：

```text
https://github.com/h675786161-prog/world-backstage
```

4. 安装后重新加载 SillyTavern。
5. 在扩展设置中启用“世界背面”，或点击页面右下角的世界球。

以后可以继续从 SillyTavern 的扩展管理页面更新。

### 手动安装

从 GitHub Releases 下载 ZIP，解压到：

```text
SillyTavern/data/<你的用户目录>/extensions/world-backstage/
```

最终目录应直接包含：

```text
world-backstage/manifest.json
world-backstage/index.js
world-backstage/style.css
```

如果出现 `world-backstage/world-backstage/manifest.json`，说明多套了一层目录。

## 第一次使用

推荐按这个顺序来：

1. 打开右下角世界球。
2. 选择连接方式：跟随当前酒馆、酒馆已存方案，或独立接口。
3. 校准主世界历法与时间。
4. 旧长聊天先执行一次“建立初始记忆档案”。
5. 保持长期记忆注入开启。
6. 正常聊天，让世界背面逐步整理正文并维护世界状态。
7. 确认记忆稳定后，再决定是否开启“自动隐藏已归档楼层”。

完整步骤和各开关说明见 **[使用手册](docs/USER-GUIDE.md)**。

## 长篇记忆与自动隐藏

这部分是 2026-09-25 合并后的重点。

### 长篇记忆回读

世界背面会为 user / assistant 正文建立逐楼 L0 摘要，再向上整理持续经历与阶段摘要。

正文需要旧信息时，会优先召回相关的精确楼层。开局、初见、暗号、密码、交接物品、敲门节奏、先后动作等内容，会尽量从原始对应记忆中找回，而不是只依赖一段笼统大总结。

### 自动隐藏已归档楼层

开关默认关闭。

开启后：

- 只隐藏已经有可靠逐楼记忆覆盖的旧正文；
- 始终保留最近 **5 层**已归档正文；
- 所有尚未归档或缺少 L0 的楼层继续可见；
- 使用 SillyTavern 原生隐藏语义，只从模型上下文移除，不删除聊天；
- 用户自己手动 `/hide` 的内容不会被世界背面恢复；
- 关闭自动隐藏、记忆系统、长期记忆注入或世界背面本体时，会恢复世界背面自己隐藏的楼层。

详细行为、恢复方式与排错见 **[使用手册 → 长篇记忆与自动隐藏](docs/USER-GUIDE.md#长篇记忆与自动隐藏)**。

## 数据与安全

- 世界状态保存在当前聊天 metadata 中。
- 每个 AI swipe 的分支快照保存在对应消息 `extra` 中。
- 持续摘要、长期事实、阶段经历、伏笔和整理进度跟随当前聊天保存。
- 独立 API 配置保存在本机 SillyTavern 扩展设置中，不进入世界状态导出。
- 模型输出只作为候选；失败、空回复和截断不会无理由推进世界状态。
- 自动隐藏不删除消息，关闭后可恢复由世界背面自动隐藏的楼层。

建议在大改设置、长期回溯或迁移设备前导出一次世界状态备份。
