# 世界观通讯适配层

世界背面的“通讯”是观察入口，不等于世界里存在现代即时通讯软件。

本层使用确定性规则，从当前世界状态、人物背景、近期事件与长期事实中判断通讯生态，并在社交后台请求前注入约束。它不额外调用模型。

## 核心规则

- `accepted / pending / friend_request / remove_friend / posts / group` 保留为兼容数据协议名，不作为世界事实。
- 古代/低技术世界默认采用书信、口信、信使、驿传等已有合理媒介；不得因为 UI 有“消息”就瞬间送达。
- 魔法世界只有在设定明确支持时才能使用传讯术、通讯水晶、使魔传信等远程媒介；“存在魔法”本身不构成通讯能力证据。
- 科幻世界使用已确认的终端、通讯器、星网等，并服从距离、网络和世界规则。
- 无明确证据时不默认手机、互联网、魔法通讯或未来科技。
- 后台知道一条消息，不等于角色已经收到；`saw` 必须经过真实送达条件判断。
- 延迟通讯可以在后续世界时间推进后，由低频社交脉冲自然处理。
- 公开动态只是“主动公开/半公开传播”的兼容概念；不存在合理公开渠道时允许零条。

UI 术语与视觉适配留给后续单独重构，本层只先保证世界逻辑正确。
