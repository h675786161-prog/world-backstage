# 世界书人物导入修复

人物名与条目标题分开处理。像「林舟－外貌」「林舟－经历」且关键词都明确为「林舟」的条目，规则导入会组装成一个人；同条目里重复的同名角色块会保留后面的补充资料。不同来源仅仅重名时，AI 审校默认不勾选，用户可以单独建立、补充指定的已有卡，或与上方同名草稿合并。

在「人物设置 → 世界书人物导入 → 高级手动挑选」扫描、勾选条目后，可以选择规则导入或「由 AI 整理后导入」。AI 走人物模块的连接和输出配置，按片段整理来源原文，结果先进入审校；确认后才写入。源文重合度只检查文字出处，人物归属仍需人工确认。未通过原文核对的片段会列在报告里，低重合栏位默认不写入。

身份、外貌、人格、背景与关系、说话习惯、行为边界不再按旧的 360～900 字限制保存。新增「能力与限制」，可填写效果、范围、触发条件、代价、弱点。完整来源正文和多条来源信息随卡保存；常规推演不能改写这些作者资料。重新导入只补空栏，或继续合并尚未手动改动过的导入栏位；作者手填内容保留。

保存长度与模型预算分离：长资料不会从存档中截掉；发给推演/观测模型时仍使用独立长度预算，超长资料保留头尾并标记节选，避免能力末尾的限制被直接丢掉。中间未展示的内容仍可在人物卡中查看，但不保证每轮模型都读到。

取消整理、换世界书、切聊天都会使任务或审校草稿作废，迟到结果不能写进当前聊天。AI 整理中的失败批次会保留在报告，已经生成的其他草稿仍可逐项确认。
