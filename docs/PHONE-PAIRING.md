# 手机配套说明

世界背面 2.5.9 配套小手机 0.3.0-alpha.28：https://github.com/Lenore-111/yellowmi-24-pro-max-plus

安装或手动更新两份扩展后刷新页面，在原聊天初始化世界背面，再将手机设置切到世界背面模式。两边均关闭自动更新，请保持配套更新。

手机可以接受或拒绝好友申请、新建私聊、发送私聊和群聊消息、标记已读、建群，以及点赞和评论朋友圈。世界背面是世界模式社交状态的写入与保存权威；保存失败会报告失败，成功确认后才通知手机。

私密动态、私密事件和人物后台心理不通过手机公开接口展示。切聊天或分支后，旧操作不能写入当前世界；手机还会检查角色、玩家身份和手机模式，丢弃旧确认结果。

世界模式电话、短信暂不提供通话和收发能力。独立手机模式的角色互动保存在独立记录中，不修改世界背面状态。

更新保留已有聊天状态键、通知和社交记录结构。更新前备份聊天，遇到问题保留原数据和两份扩展版本；恢复时使用此前配套版本和必要的聊天备份，不要求删除聊天。
